This repository provides the basic implementation of the paper “A Partially Supervised Joint Segmentation Method for Farmland and Rural Roads from Single-Class Annotated Remote Sensing Datasets.” The released code mainly includes the **model architecture** and **training pipeline** used in our method. Due to differences in datasets, environments, and experimental settings, some implementation details are not included in this repository. For further information regarding data preprocessing, training strategies, parameter settings, and experimental configurations, please refer to the corresponding paper.
